Resumen de etiquetas HTML (para examen)

1. Estructura básica

<!doctype html> — declara HTML5. <html>, <head>, <body>.

<!doctype html>
<html lang="es">
  <head>
    <meta charset="utf-8">
    <title>Mi página</title>
  </head>
  <body>
    <h1>Hola</h1>
  </body>
</html>

2. Metadatos y recursos

  • Meta, title, link, style, script.
<head>
  <meta name="viewport" content="width=device-width,initial-scale=1">
  <link rel="stylesheet" href="estilos.css">
  <style>/* CSS rápido */</style>
  <script src="app.js" defer></script>
</head>

3. Estructura semántica

Uso de etiquetas semánticas para mejorar accesibilidad y SEO.

<header>Cabecera con logo y nav</header>
<nav><ul><li><a href="#">Inicio</a></li></ul></nav>
<main>
  <article><h2>Artículo</h2><p>Contenido...</p></article>
  <aside>Barra lateral</aside>
</main>
<footer>Pie de página</footer>

4. Encabezados y texto

Ejemplos de títulos, párrafos, énfasis y bloques de código.

<h1>Título principal</h1>
<h2>Subtítulo</h2>
<p>Un <strong>párrafo</strong> con <em>énfasis</em>.<br>Nueva línea.</p>
<blockquote>Cita larga...</blockquote>
<pre><code>console.log('hola');</code></pre>

5. Agrupación genérica

Div y span para agrupar cuando no hay semántica adecuada.

<div class="tarjeta">
  <h3>Título tarjeta</h3>
  <span class="etiqueta">Nuevo</span>
</div>

6. Enlaces y navegación

Ejemplo de enlace y menú de navegación.

<nav>
  <ul>
    <li><a href="index.html">Inicio</a></li>
    <li><a href="#contacto" target="_self">Contacto</a></li>
  </ul>
</nav>

7. Imágenes y multimedia

Imagen con alt, picture responsive y video con subtítulos.

<img src="logo.png" alt="Logo de la empresa" loading="lazy">

<picture>
  <source srcset="imagen.webp" type="image/webp">
  <img src="imagen.jpg" alt="Descripción">
</picture>

<video controls>
  <source src="video.mp4" type="video/mp4">
  <track kind="subtitles" srclang="es" src="sub.vtt" label="Español">
</video>

8. Listas

Listas ordenadas, desordenadas y definiciones.

<ul>
  <li>Elemento 1</li>
  <li>Elemento 2</li>
</ul>

<ol>
  <li>Primero</li>
  <li>Segundo</li>
</ol>

<dl>
  <dt>HTML</dt>
  <dd>Lenguaje de marcado</dd>
</dl>

9. Tablas

Ejemplo de tabla semántica con thead y tbody.

<table>
  <caption>Ventas 2025</caption>
  <thead><tr><th>Mes</th><th>Ventas</th></tr></thead>
  <tbody>
    <tr><td>Enero</td><td>1000</td></tr>
    <tr><td>Febrero</td><td>1200</td></tr>
  </tbody>
</table>

10. Formularios y controles

Formulario con etiquetas, distintos tipos y agrupación.

<form action="/enviar" method="post">
  <label for="nombre">Nombre:</label>
  <input id="nombre" name="nombre" type="text" required>

  <fieldset>
    <legend>Preferencias</legend>
    <label><input type="checkbox" name="news"> Newsletter</label>
  </fieldset>

  <label for="pais">País:</label>
  <select id="pais"><option>España</option></select>

  <button type="submit">Enviar</button>
</form>

11. Elementos interactivos y web components

Detalles desplegables, dialog y template.

<details>
  <summary>Más información</summary>
  <p>Texto oculto al inicio.</p>
</details>

<template id="tpl"><div class="item">Plantilla</div></template>

12. APIs y atributos globales importantes

Uso de id, class, data-*, aria-* y loading.

<div id="miId" class="destacado" data-info="123" role="region" aria-label="Sección principal">
  <img src="foto.jpg" alt="Foto" loading="lazy">
</div>

13. Etiquetas obsoletas / evitar

Ejemplos de etiquetas heredadas que no se deben usar; sustituir por CSS/semántica.

<!-- Evitar -->
<center>Texto centrado con <font> color="red"</font></center>

<!-- Usar en su lugar -->
<div style="text-align:center;color:red">Texto centrado</div>

14. Consejos rápidos para el examen

  • Semántica > presentacional. Accesibilidad y atributos importantes.
<!-- Ejemplo rápido: formulario accesible -->
<label for="email">Email</label>
<input id="email" type="email" aria-required="true" required>
